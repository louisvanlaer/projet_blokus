# Projet S1 Vitrant_Paugam_Volay_Vanlaer

## Description
``` 
Ce projet est destiné à la création d'un jeu vidéo blokus. 
```

## Fonctionnalités
``` 
- Sauvegarder et charger une partie
- Historique des coups
(Pas eu le temps de les développer)
```

# Structure du projet
```
docs : Contient les documents comme les spécifications fonctionnelles.
src : Contient le code source.
tests : Contient les tests.
```

## Installation
```
git clone git@gitlab.cri.epita.fr:timothe.volay/projet-s1-vitrant_paugam_volay_vanlaer.git
S'assurer d'avoir bien installer python
```

## Utilisation
```
Pour jouer à Blokus, après avoir cloner le dépôt en utilisant la commande `git clone`. Il faut accédez au répertoire `src` en exécutant `cd src`, puis lancez le jeu avec la commande `python -X utf8 main.py`.

```

## Contribution
```
Pour contribuer, veuillez créer une branche à partir de `main` qui va permettre de forker le projet (`git checkout -b feature/NouvelleFonctionnalite`). Il faut bien penser à commit avec une explication simple et clair de la modification pour s'y retrouver (`git commit -m "Ajout d'une nouvelle fonctionnalité"`). Push la branche avce la commande (`git push origin feature/NouvelleFonctionnalite`) et pour fusionner votre branche avec main il faut utiliser une merge request. Enfin merci de bien respecter le langage pour faire le projet qui est codé  en python python.
```
